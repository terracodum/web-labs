# Лабораторная работа №2. Реактивность

В данной работе предлагается использовать реактивные фреймворки для создания web-приложения. Основной задачей является разработка переиспользуемого реактивного компонента таблицы, использующего данные, передаваемые в качестве параметров. При реализации компонента разрешается использование библиотек компонентов.

Переходы по созданным в предыдущей лабораторной работе страницам теперь должны выполняться с помощью роутера.

## Результат

В результате выполнения лабораторной работы должно получиться SPA, содержащее два маршрута, отображающих переиспользуемый компонент таблицы.

# Лабораторная работа №4. Строгая типизация

В данной лабораторной работе необходимо ввести строгую типизацию получаемых через API данных.

## Задание

- Для проверки типов поступающих данных рекомендуется использовать библиотеку `io-ts`.
- Получаемые с помощью axios данные необходимо декодировать с помощью созданных кодеков.
- Для проверки соответствия данных кодеку предлагается создать функцию `decodeOrThrow`, использующую `fp-ts` для обработки `Either`.

## Результат

В результате выполнения лабораторной работы должен получиться механизм строгой типизации данных, получаемых через API.

# Лабораторная работа №3. Стороннее API

В данной лабораторной работе предлагается использование стороннего API с целью получения данных для заполнения таблиц.

## Задание

Необходимо реализовать:

- единый класс-сервис для совершения запросов с использованием axios;
- классы-сервисы для получения данных через API (рекомендуется использовать https://www.nobelprize.org/about/developer-zone-2/).

Таблицы должны поддерживать пагинацию, а также фильтрацию.

# Лабораторная работа №5. Кеширование

В данной лабораторной работе нужно добавить возможность кеширования данных, получаемых с помощью API.

## Задание

Кеширование предполагает возможность работы приложения даже при отсутствующем интернет соединении. Для реализации необходимо проапгрейдить web-приложение до PWA и внедрить service-worker, который будет отвечать за логику кеша.

## Результат

В результате выполнения полученное web-приложение должно иметь возможность отображать данные при отсутствии соединения и обновлять их при восстановлении подключения.
